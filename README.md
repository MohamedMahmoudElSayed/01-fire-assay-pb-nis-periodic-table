# Fire Assay Pb/NiS Periodic Table

An interactive 118-element reference for lead fire assay (Pb-FA) and nickel sulfide fire assay (NiS-FA), with element details, method context, filters, and image export.

## Run locally

Open [`index.html`](index.html) in a modern browser. The project is a self-contained HTML page with no build step or external JavaScript dependencies.

## GitHub Pages

To host the page, open **Settings > Pages**, choose **Deploy from a branch**, select the default branch and `/ (root)`, then save.

## Disclaimer

This is an informational reference, not a validated laboratory procedure. Confirm methods, detection limits, and operating conditions against applicable standards and validated laboratory procedures.
